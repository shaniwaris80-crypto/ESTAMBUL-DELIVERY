🔗 Seguimiento por WhatsApp

Cuando el Rider pulsa «Aceptar pedido», el sistema intenta enviar automáticamente el enlace por SMS (solo si hay autorización y Twilio está activado). WhatsApp normal queda como opción manual de respaldo.

Para SMS automático, elige SMS, indica teléfono y autorización. Si Twilio no está disponible, Rider mostrará un aviso y ofrecerá el enlace de seguimiento para compartir. «Enviar seguimiento» sigue como respaldo manual. Desde Riders puedes configurar un número de trabajo para que el cliente también llame al repartidor.
